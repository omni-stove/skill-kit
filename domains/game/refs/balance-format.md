# Balance doc format

A balance doc holds one system's numbers, the curves relating them, and the reason for each. Behaviour lives in the mechanic doc.

```markdown
# [System] Balance

## Goal
What the balance should achieve, in measurable terms.

## Values
| Parameter | Value | Unit | Rationale |
|---|---|---|---|

## Curves
Formula or curve shape for each set of related values: cost ramps, XP-to-level, damage falloff.

## Tuning Notes
Known tensions, what to watch in play-test, values likely to change.

## Open Questions
Undecided values and what data would settle each.
```
