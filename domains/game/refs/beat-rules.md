# Beat rules

Give each section one beat, and list the beats in route order for a campaign.

Settle with the user, for each beat, what the pieces cannot hold:

- the controls the player is taught there, in order
- each set piece that changes the map at runtime — what falls, opens, closes, or is picked up or dropped — located by piece id or coordinates
- what each enemy and ally there does
- the landmark that draws the player on
- why the section breaks a rule it was laid out by, where it does

Write each note as one fact the person building the section acts on. Put a note on a piece or spawn instead when it concerns that one alone: a named character, a landmark, a piece that changes at runtime. Put in `backdrop` what is seen beyond the bounds, and the landmarks seen from more than one section.
