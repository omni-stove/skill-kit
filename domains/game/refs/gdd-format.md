# Game design document (GDD) format

The GDD holds what the game is and how it works. Per-system detail lives in the mechanic / balance / level docs, linked from here.

```markdown
# [Game Title]

## Overview
One paragraph: what the player does, the core loop, the hook. Genre and platform in one line.

## Design Pillars
2–4 principles, each able to reject a feature.

## Core Loop
The moment-to-moment loop (seconds) and the session loop (minutes), as steps.

## Mechanics
One bullet per system, linking its mechanic doc.

## Progression
How the player and the game state advance over a playthrough: unlocks, difficulty curve.

## Controls
Input scheme per platform.

## Content Scope
Counts and kinds: levels, enemies, items, biomes.

## Art & Audio Direction
Palette, camera, references.

## Technical Constraints
Target hardware, engine, framerate, limits.

## Open Questions
Decisions still `TBD` and what blocks each.
```
