For a server: use the one the user provides or a well-known one they name. Configure it project-scoped: claude mcp add --scope project <name> -- <command> [args...], or claude mcp add --scope project --transport http <name> <url>; a config blob the user gives goes into .mcp.json, merged into its mcpServers object, with secrets as env references, never literal tokens. Run claude mcp list (claude mcp get <name> for detail) and confirm the server connects; on failure surface the error and the fix and stop. Then run .agents/skills/setup-mcp/scripts/record.sh <tool prefix, e.g. mcp__unity__>.
