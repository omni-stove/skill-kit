# contest-rules の書き方

各ファイルは `## $CONTEST_RULES` で始め、対象の一文、必要なら方針の段落、`### Evaluation Criteria` の箇条を続ける。

- 作品1本をどう評価するかだけを書く。賞の種類、選考の段階、他の応募作との比較や順位は書かない。大賞か否かの判定は judge-full が持つ。
- 評価項目は長所があることを述べる肯定形で書く。
- 文末は言い切りにする（「〜がある。」「〜している。」）。
- 判定の物差しは一本にする。複数置くなら主従を書く。
- 方針文と項目、項目同士を矛盾させない。方針で形や題材を問わないとした範囲の長所は、「〜なら」の条件付きで書く。
- 同じ長所は1項目でだけ扱う。
- 重みを付ける項目には「この項を最も重く見る」と書く。書かない重みは審査員が決める。評価軸の異なる項目の間に優先順位は付けない。
- 範囲・量・比較対象は、審査員が作品から確かめられる語で書く。複数の要素を並べたら、すべて要るのかどれかでよいのかを書く。
- 既存ルールを直すときは、何を評価するか、その重み、必須か任意かを修正前と変えない。
