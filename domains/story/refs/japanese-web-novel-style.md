# Japanese Web Novel Style Rules

- Split a narration sentence well over ~80 chars where its action or object changes
- Never end narration on a bare noun, keeping any the file already has; end on a noun + だった only where the noun is itself the new thing the POV saw, heard, or felt — max 1 per paragraph, a paragraph between any two, and max 1 per chapter for a look or voice
- End what the POV concludes now on だ, not だった
- Use a metaphor only where plain prose falls short — max 1 per paragraph, 2 per scene
- State a gesture or posture once, not as a multi-step procedure
