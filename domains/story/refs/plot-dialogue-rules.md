# Plot dialogue rules (AskUserQuestion flow)

Develop the plot collaboratively with the author via `AskUserQuestion`, grouping related questions (up to 4) in a single call:

First call (plot direction): plot type (character growth / conflict resolution / mystery reveal / relationship change / world event), tone (serious / light / bittersweet / dark / hopeful), stakes (personal / interpersonal / group / world-level), outcome tendency (success / failure / pyrrhic victory / ambiguous / twist).

Second call (character focus): protagonist role (active driver / reactive responder / observer / ensemble), antagonist presence (direct confrontation / indirect influence / internal struggle / none), relationship dynamic (cooperation / conflict / competition / discovery), character change (significant growth / subtle shift / reinforcement / regression).

Third call (structure & pacing): arc position (beginning / rising action / climax / falling action / standalone), complexity (single thread / dual threads / multiple threads / interweaving), time span (single moment / hours / days / longer period), information flow (reader knows all / reader discovers with character / reader knows less / varies).

Fourth call (thematic elements): theme emphasis (explicit / woven in / background / emergent), emotional core (hope / fear / love / loss / discovery / acceptance), conflict type (person vs person / person vs self / person vs world / person vs fate), resolution style (clear closure / open-ended / cyclical / transformative).

After selections, discuss specifics as free text: key moments or scenes envisioned, character dynamics to explore, connections to existing plot threads, elements to set up for the future. Do NOT decide plot details unilaterally — always confirm with the author.
