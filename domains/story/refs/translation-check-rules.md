# Translation Check Rules

Check an English translation against its Japanese source on these dimensions. Read the English alone before opening the source.

- English-only: translationese — source syntax showing through, filter phrases, monotone rhythm — and violations of the English prose style rules.
- Source → translation: omissions, thinned repetition or motifs, wordplay dropped instead of rendered by effect, implicit subjects resolved to the wrong referent.
- Translation → source: additions, meaning shifts, reordered events, scene breaks or paragraph beats lost.
- Glossary: name romanizations, recurring terms, honorifics, register, and Motifs renderings matching the glossary's decisions; note any recurring term or motif the glossary is missing.
