---
name: analyze
description: 引数で指定されたファイルの文体癖と繰り返しを調査する。Use when the user wants to investigate a Japanese fiction file's stylistic habits and repetitions (文体癖・繰り返し) and names a target file.
---

The user specifies the target file path to investigate.

Bashツールを使って機械的に集計し、その結果を解釈して報告する。
ファイルをReadでコンテキストに読み込まないこと。

チェック項目を限定せず、集計結果から気になるものは何でも拾う。以下は検出すべきパターンの例であり、これに限らない：

- 同じ語・フレーズの多用
- 文末の偏り（「た。」の総量ではなく、同一バリエーションの偏りや3行以上の連続を見る）
- 文頭の偏り
- 構文パターンの反復
- 描写手法の偏り
- 特定の言い回しへの依存

会話文と地の文は区別して集計すること。

出力:

- **気になる点**: 問題の大きい順に番号付きリスト。ファイル名・行番号・具体例つき
- **文末分布**: パターン / 回数 / 割合 のテーブル
- **頻出語**: 語 / 回数 のテーブル
- 網羅性より、本当に気になる点を優先して報告する

分析結果の出力後、AskUserQuestion で修正するかを確認する。

**質問:** 「修正する項目を選んでください」

**選択肢の構成（multiSelect, 最大4つ）:**
- 「すべて修正」を先頭に置く
- 気になる点の上位3つを優先度順に並べる

ユーザーが項目を選択した場合、選択された各項目について対象ファイルを直接編集して修正を適用する。
