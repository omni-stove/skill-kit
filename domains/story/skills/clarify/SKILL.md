---
name: clarify
description: 専門知識がない読者にもわかりやすい表現に書き換える。Use when the user wants to rewrite difficult or jargon-heavy passages in a text into expressions readable by non-specialists, naming a target file.
---

The user specifies the target file path to clarify.

ユーザーが指定したファイルを読み、わかりにくい箇所を特定する：

- 専門用語・業界用語
- 難読漢字・古語
- 前提知識が必要な表現
- 説明なしに登場する固有名詞・概念
- 複雑すぎる文構造

各箇所について、行番号・原文・改善案を示し、改善の理由を簡潔に添える。ユーザーの承認を得てから書き換える。

やること：

- 専門用語に簡潔な説明を添える（地の文で自然に補足）
- 難読漢字にルビ相当の補足、または平易な言い換え
- 長い一文を適切に分割
- 抽象的な概念を具体例で補う

やらないこと：

- 作品の雰囲気や文体を損なう過度な簡略化
- キャラクターの口調・個性を変える
- ストーリーや設定の変更
- 会話文の中の専門用語（キャラが使う分には自然）

出力形式：

```
## 改善提案

### 1. L42: 専門用語
原文: 「彗星の近日点通過を観測した」
改善案: 「彗星が太陽に最も近づく瞬間——近日点通過を観測した」
理由: 「近日点」は天文学用語。初出時に簡潔な説明を挿入。

### 2. L78: 複雑な文
原文: （長い文）
改善案: （分割した文）
理由: 一文が長く読みづらい。
```

- ジャンル（SF、歴史、ファンタジー等）に応じた専門用語の扱いを考慮する
- 読者層を想定し、過度な説明で冗長にならないよう注意
- 「わからなくても雰囲気で読める」箇所はあえて残す判断もあり
