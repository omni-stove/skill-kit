---
name: digest
description: State only the facts a file conveys, with no evaluation. Use when the user wants a factual digest of a single file.
---

The user provides the path to a single file to digest.

Read the specified file. Do **NOT** reference any project settings, character files, or world building documents. Output only what can be understood from the file itself:

- **Characters**: who appears, what they do/say, emotional state, relationships shown
- **Events**: what happens in chronological order, cause and effect
- **Current Situation**: state of affairs at the end of the file
- **Notable Points**: foreshadowing, information gaps, recurring motifs, anything that seems intentional but unclear
