# unnatural

日本語の小説ファイルまたはディレクトリの地の文から、不自然な語の使い方や構文を探す。会話文は対象外。

平行四辺形はユーザーに見えて、答えるもの。

```mermaid
flowchart TD
  input{ファイルか<br/>ディレクトリか?}
  input -- "ファイル" --> one[ファイルの地の文をチェック]
  input -- "ディレクトリ" --> many[すべてのファイルの<br/>地の文を並行してチェック]
  one --> found
  many --> found{問題がある?}
  found -- "ない" --> none[/問題なし/]
  found -- "ある" --> report[/"深刻度別の指摘 +<br/>どれを直すかを聞く"/]
  report --> fix[選んだ項目を直す]
```
