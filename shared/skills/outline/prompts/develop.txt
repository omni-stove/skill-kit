## 時系列

```mermaid
flowchart TD
    subgraph P1["<phase>"]
        E1["#1 <出来事>"]
    end
    subgraph P2["<phase>"]
        E2["#2 <出来事>"] --> E3["#3 <出来事>"]
        E4["#4 <出来事>"]

```

## 構成

```mermaid
flowchart TD
    subgraph S1["<section title>"]
        direction TB
        S1E3["#3 <短い出来事>"] --> S1E1["#1 <短い出来事>"]
    end
    subgraph S2["<section title>"]
        direction TB
        S2E5["#5 <短い出来事>"]
    end
    S1 --> S2
```

- 時系列: every event in the order it happens in the story world. One node `E<n>` per event,
  labelled `#<n>` and the event in full, no timestamp, `-->` to the next. Branch for
  concurrent events and merge them with `&` where they meet. A `subgraph P<k>` per phase
  holds the edges inside it; write each edge between phases outside, right after the
  `end` of the phase it leads into.
- 構成: the sections in the order the story tells them, one `subgraph S<m>` each with
  `direction TB`, its title carrying the section's number or kind and its viewpoint
  character when known, and `-->` from each to the next on one line at the end. Inside, one
  node `S<m>E<n>` per event it shows, in the order it shows them, labelled `#<n>` and a
  shortened form of the event.
